Política de Privacidade

Impoclick — plataforma web e extensão para Chrome · Última atualização: 14 de setembro de 2026

Esta política explica quais dados o Impoclick coleta, para que eles são usados e quais são os seus direitos. Ela vale tanto para o site impoclick.com.br quanto para a extensão Impoclick — Viabilidade no Mercado Livre.

Resumo: coletamos apenas o necessário para autenticar você e calcular a viabilidade dos produtos. Não vendemos seus dados, não os compartilhamos com terceiros para publicidade e não usamos seus dados para nenhuma finalidade alheia à função principal do produto.

1. Quem é o controlador dos dados

O Impoclick é o controlador dos dados tratados por este serviço. Para qualquer assunto relacionado a privacidade, o contato é contato@impoclick.com.br.

2. Dados que coletamos

DadoQuando é coletadoPara quê
E-mail e senha No cadastro e no login Autenticar você e vincular a extensão à sua conta do Impoclick
Token de sessão Após o login bem-sucedido Manter você conectado sem pedir a senha a cada uso
Dados de produtos e custos que você cadastra Quando você usa a plataforma Calcular custo de importação, margem e viabilidade de venda
Identificador e preço do anúncio do Mercado Livre que você está visitando Quando você abre uma página de anúncio com a extensão ativa Comparar o preço do anúncio com os seus custos e exibir o resultado na tela

O que a extensão não faz

  • Não lê páginas fora dos domínios do Mercado Livre (mercadolivre.com.br e mercadolibre.com).
  • Não coleta histórico de navegação, cookies de terceiros, localização, contatos, dados financeiros de pagamento nem conteúdo de formulários de outros sites.
  • Não executa código remoto: todo o código da extensão está contido no pacote publicado na Chrome Web Store.

3. Como usamos os dados

Os dados são usados exclusivamente para operar o serviço: autenticar seu acesso, salvar seus cálculos, exibir a análise de viabilidade nos anúncios e dar suporte quando você solicita. Não fazemos perfilamento publicitário, não vendemos nem transferimos dados a corretores de dados, e não usamos os dados para avaliar crédito ou conceder empréstimos.

4. Onde os dados ficam

  • No seu navegador: o token de sessão é guardado localmente via chrome.storage.local, acessível apenas pela própria extensão. Ele é apagado quando você sai da conta ou remove a extensão.
  • Nos nossos servidores: conta e dados cadastrados ficam no Supabase (infraestrutura de banco de dados e autenticação) e as funções da API rodam na Vercel. Ambos atuam como operadores, sob contrato, processando dados apenas em nosso nome.
  • Mercado Livre: consultas públicas de anúncios, frete e categorias são feitas às APIs oficiais do Mercado Livre. Nenhum dado pessoal seu é enviado nessas consultas.

5. Compartilhamento com terceiros

Não comercializamos dados pessoais. O compartilhamento ocorre apenas com os operadores de infraestrutura citados acima, com processadores de pagamento quando você contrata um plano, e quando houver obrigação legal ou ordem judicial.

6. Retenção e exclusão

Mantemos seus dados enquanto a sua conta existir. Você pode pedir a exclusão da conta e de todos os dados associados a qualquer momento por contato@impoclick.com.br; o atendimento ocorre em até 15 dias. Desinstalar a extensão apaga imediatamente os dados guardados no navegador, mas não exclui a sua conta na plataforma.

7. Segurança

Todo o tráfego usa HTTPS. Senhas são armazenadas com hash pelo provedor de autenticação — nunca em texto puro. O acesso à API exige token válido e o servidor restringe cada usuário aos próprios dados.

8. Seus direitos (LGPD)

Conforme a Lei nº 13.709/2018, você pode solicitar confirmação de tratamento, acesso, correção, anonimização, portabilidade, exclusão dos dados e revogação do consentimento. Basta escrever para contato@impoclick.com.br.

9. Crianças

O serviço é destinado a maiores de 18 anos e não é direcionado a crianças ou adolescentes.

10. Alterações nesta política

Mudanças relevantes serão publicadas nesta página com a data de atualização revisada. O uso continuado do serviço após a publicação implica concordância com a versão vigente.
